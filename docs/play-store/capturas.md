# Lista de capturas para Play Store

Requisitos de Play: mínimo 2 capturas de teléfono por app (recomendado 4 a 8). PNG o JPEG,
lado corto ≥ 320 px, lado largo ≤ 3840 px, relación máxima 2:1. Gráfico de funciones: 1024×500.
Ícono de la ficha: 512×512 PNG (ver `ICONOS.md`).

Toma las capturas con un emulador o dispositivo real, con datos de prueba creíbles (sin datos personales reales).
Idioma: español.
